## 0. 핵심 방향 전환 — "정확한 팩트의 빠른 전달"

4/23 미팅 결과 프로젝트의 본질 가치를 재정의했습니다. AI 시사점이 아닌 **검증된 팩트와 재무 연결**이 차별점입니다.

| 구분 | 기존 (v1) | 변경 (v2) |
|---|---|---|
| 본질 가치 | AI가 시사점·통찰 제공 | **정확한 팩트의 빠른 전달** |
| AI 역할 | 시사점 자동 생성이 핵심 | **검증된 팩트 + 재무 연결 (시사점은 옵션)** |
| 차별점 | 5개 축 가중치 분류 | **멀티에이전트 검증 체계 + 정확도** |
| 표시 방식 | "긴급/주목/참고" | **"○○ 동향 + 근거 데이터"** |
| 알림 채널 | Slack | **이메일 (1순위) + MS Teams (검토)** |
| 시사점 생성 | ImplicationAgent로 필수 | **보류 (정확도 검증 우선)** |

미팅에서 받은 핵심 질문: **"시중 AI로 다 할 수 있잖슴 → 차별점?"**
→ 답: 정확도 다단계 검증 + 뉴스↔재무 연결 + SI 도메인 지식 + 선제 탐지 (§8 참조)

### 2.5 식별된 이슈

#### ① urgent 0건 — 임계값 보수성

**현상**: 5회 실행 모두 urgent 등급 카드가 한 건도 안 나옴. 86카드 전부 notable/reference.

**원인**: `ClassificationAgent` 프롬프트에 "종합 점수 80 이상 = urgent"라고만 적혀 있고, 실제 점수 계산은 GPT-4o가 프롬프트만 보고 추정. 5축 가중치도 코드가 아닌 프롬프트 안에만 존재. LLM이 보수적으로 판정하여 평범한 뉴스는 70점대에 머무름.

> **v2 방향에서 재정의**: 미팅 결과 "긴급/주목" 등급 자체가 폐기됩니다 (§1.4). 점수 보정 대신 노출도·건수·출처 신뢰도 **근거 데이터** 표기로 단순화. ClassificationAgent는 동향 카테고리(보안 / TBD / TBD)와 노출 점수만 산출하도록 축소 리팩토링.

#### ② 클러스터링 under-merge

**현상**: 125건 → 86 클러스터 (39 dedup, 31%). 같은 "삼성SDS 1분기 실적" 기사가 5개 언론에서 각각 다른 클러스터로 잡힘.

**원인**: cosine threshold 0.85가 보수적. 같은 사건을 다르게 서술한 재보도는 0.80~0.84 범위에 분포.

**개선 방향**: threshold 0.83 시도 + 제목 가중치 더 높이기 (현재 2회 반복 → 3회), false-positive 비율 모니터링.

#### ③ ClassificationAgent의 컨텍스트 부족

**현상**: 클러스터 대표 기사 1건만 LLM에 전달. "5개 언론 동시 보도"라는 신호가 미반영.

**개선 방향**: 프롬프트에 `cluster_size`, `peer_count`, `latest_pub_at` 메타데이터 추가. v2의 노출도 점수와 직결.

#### ④ RSS 키워드 매칭 실효성

**현상**: etnews/bloter 등 IT 뉴스 RSS 230건 중 peer 이름 매칭 0~1건. 피드 인프라는 정상이나 실효 수집은 거의 없음.

**판단**: Naver News + Google News로 같은 기사를 이미 커버하므로 제거 후보. 우선순위는 낮음.

## 4. 신규 핵심 기능 (v2 신규 설계)

### 4.1 IR·재무 파싱 에이전트 ⭐ 차별화 핵심

```
역할: PDF·HWP IR 자료 파싱 → 재무 지표 구조화 저장
주기: 분기별 자동 (실적 발표일 기준)
산출물:
  - 매출액, 영업이익, 사업부별 매출 비중 (시계열)
  - 채용 증감, R&D 투자, 자본적 지출 변화
  - 사업부 재편·전략 코멘트 추출

기술 스택:
  - PDF 파싱: PyMuPDF + LLM (표·차트 추출)
  - 저장: PostgreSQL `peer_financials` 테이블 (JSONB)
  - 업데이트: DART 공시 감지 시 자동 트리거
```

**삼성SDS 처리 규칙**: 물류 사업 분리, ITS만 추출

### 4.2 뉴스↔재무 연결 분석 에이전트 ⭐ 차별화 핵심

```
역할: Peer사 뉴스 발생 시 재무 데이터에서 근거·영향 추출
입력: 뉴스 (예: "LG CNS 팔란티어 파트너십")
출력:
  - 왜 했나? → 재무 변화 추적 (예: "AI 매출 비중 12%→18%")
  - 숫자로? → 관련 사업부 매출·인력 추이
  - 비교 → 동종 Peer사 동일 시기 변화

원리: 뉴스 발생일 기준 ±3개월 재무 데이터 컨텍스트 + LLM 분석
```

이게 시사점을 대체하는 차별화 포인트입니다. 시사점 대신 **숫자로 설명되는 팩트**를 제공합니다.

### 4.3 선제적 탐지 메일 알림 ⭐ 시연용

```
시나리오:
  Peer사가 보안·M&A 등 핵심 트렌드 관련 액션
  → 5분 이내 이메일 발송
  → 제목: "[AXIS 선제 탐지] LG CNS, AI 보안 솔루션 인수"
  → 본문: 한 줄 요약 + 출처 링크

폐쇄망 대응:
  - 외부 사이트 직접 접속 불가 환경 고려
  - 이메일 본문에 핵심 정보 포함
  - "리포트가 생성되었습니다" 안내 알림
```

### 4.4 글로벌 동향 + 검색량 트렌드

```
글로벌 동향:
  X·Threads 키워드 추출 (재미 요소)
  → 공통 언급 단어 → 해외 뉴스 매핑

검색량 데이터:
  Google Trends, Naver DataLab API
  → 급증 키워드 → 시장 인사이트
  → 알림에 반영 (시장 변화 신호)
```

### 4.5 시계열 이상치 탐지 (대시보드)

```
3~12개월 흐름 표시
  → 채용·투자·기사 빈도 이상치 감지
  → 갑자기 늘어난 항목 강조
  → 클릭 시 원인 추적 (관련 뉴스·재무 변화)

예: "삼성SDS, 보안 인력 채용 4주간 3배 증가"
```

## 8. 차별화 포인트 (시연 시 강조)

미팅에서 "시중 AI로 다 할 수 있잖슴 → 차별점?" 질문 받았습니다. 답변할 차별화 포인트:

```
1. 정확도 다단계 검증
   수집 → 신뢰도 분류 → 재무 검증 → 사람 검토 플래그
   "API 한 번 호출해서 답 받는 시중 AI와 다릅니다"

2. 뉴스↔재무 연결 (다른 도구에 없음)
   "왜 이 액션을 했는지 숫자로 설명"
   삼성SDS 분기 매출, LG CNS AI 매출 비중 자동 추적

3. 선제 탐지 + 폐쇄망 대응
   외부 사이트 접속 어려운 환경에서
   이메일 한 통으로 핵심 정보 전달

4. SI 특화 도메인 지식
   삼성SDS 물류 제외, ITS만 분석 등
   섬세한 도메인 룰 반영
```
