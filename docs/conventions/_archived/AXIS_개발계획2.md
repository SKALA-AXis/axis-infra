미팅에서 "정확도와 재무 연결이 우선"이라는 방향에 따라 다음 모듈을 보류합니다.

| 모듈 | 처리 | 이유 |
|---|---|---|
| `ImplicationAgent` (시사점 생성) | 보류 | 시사점은 옵션, 인간 판단 영역 |
| `ValidationAgent` (SC 검증) | 보류 | 시사점 생성 보류로 동반 보류 |

| 5개 축 가중치 ClassificationAgent | **수정** | "긴급/주목" 폐기 → 노출도·건수 기반 점수로 단순화 |
| Slack Webhook 발송 | **변경** | 이메일·MS Teams로 전환 |

> 보류된 모듈은 코드를 삭제하지 않고 `src/agents/_deprecated/` 하위로 이동. 추후 복구 가능하게 유지.

## 3. 신규 핵심 기능 (지금 없음, 신규 설계)

### 3.1 IR·재무 파싱 에이전트 ⭐ 차별화 핵심

```
역할: PDF·HWP IR 자료 파싱 → 재무 지표 구조화 저장
주기: 분기별 자동 (실적 발표일 기준)
산출물:
  - 매출액, 영업이익, 사업부별 매출 비중 (시계열)
  - 채용 증감, R&D 투자, 자본적 지출 변화
  - 사업부 재편·전략 코멘트 추출

기술 스택:
  - PDF 파싱: PyMuPDF + LLM (표·차트 추출)
  - 저장: PostgreSQL `peer_financials` 테이블 (JSONB)
  - 업데이트: DART 공시 감지 시 자동 트리거
```

**삼성SDS 처리 규칙**: 물류 사업 분리, ITS만 추출

### 3.2 뉴스↔재무 연결 분석 에이전트 ⭐ 차별화 핵심

```
역할: Peer사 뉴스 발생 시 재무 데이터에서 근거·영향 추출
입력: 뉴스 (예: "LG CNS 팔란티어 파트너십")
출력:
  - 왜 했나? → 재무 변화 추적 (예: "AI 매출 비중 12%→18%")
  - 숫자로? → 관련 사업부 매출·인력 추이
  - 비교 → 동종 Peer사 동일 시기 변화

원리: 뉴스 발생일 기준 ±3개월 재무 데이터 컨텍스트 + LLM 분석
```

이게 시사점을 대체하는 차별화 포인트입니다. 시사점 대신 **숫자로 설명되는 팩트**를 제공합니다.

### 3.3 선제적 탐지 메일 알림 ⭐ 시연용

```
시나리오:
  Peer사가 보안·M&A 등 핵심 트렌드 관련 액션
  → 5분 이내 이메일 발송
  → 제목: "[AXIS 선제 탐지] LG CNS, AI 보안 솔루션 인수"
  → 본문: 한 줄 요약 + 출처 링크

폐쇄망 대응:
  - 외부 사이트 직접 접속 불가 환경 고려
  - 이메일 본문에 핵심 정보 포함
  - "리포트가 생성되었습니다" 안내 알림
```

### 3.4 글로벌 동향 + 검색량 트렌드

```
글로벌 동향:
  X·Threads 키워드 추출 (재미 요소)
  → 공통 언급 단어 → 해외 뉴스 매핑

검색량 데이터:
  Google Trends, Naver DataLab API
  → 급증 키워드 → 시장 인사이트
  → 알림에 반영 (시장 변화 신호)
```

### 3.5 시계열 이상치 탐지 (대시보드)

```
3~12개월 흐름 표시
  → 채용·투자·기사 빈도 이상치 감지
  → 갑자기 늘어난 항목 강조
  → 클릭 시 원인 추적 (관련 뉴스·재무 변화)

예: "삼성SDS, 보안 인력 채용 4주간 3배 증가"
```

## 4. UI/UX 개선 사항

### 4.1 대시보드 (메인)

```
변경 전 → 변경 후
─────────────────────────────────────
이슈 카드           → ○○ 동향 카드
긴급/주목/참고      → 노출도·건수·출처 신뢰도
Peer 증감률 추이    → 주요 동향 기사 (시계열)
오늘의 키워드       → 유지 (발표용)
선제 탐지 (없음)    → 신규 추가 (메인 노출)
```

### 4.2 탭 재구성

```
유지
├── Dashboard          (메인)
├── Briefings (일간)   (1순위)
├── Peers              (재무·전략 분석)
└── Search (챗봇)

├── Reports 탭         → 챗봇 내부로 통합
└── Articles 탭        → Dashboard 하단 또는 제거

신규
├── Trends             (글로벌 동향, 검색량)
└── Admin              (스케줄러, API 비용, 로그)
```

### 4.3 알림 시스템 변경

```
기존: Slack Webhook
변경:
  1순위: 이메일 (양식 — 언제·누가·요약 한 줄)
  2순위: MS Teams (검토)
  제외: Slack (실무 미사용), 문자 (과금 부담)
```

알림 주기:
- 일간 브리핑: 매일 오전 (1회)
- 선제 탐지: 즉시 (5분 이내)
- 주간 리포트: 월요일 (선택)

## 7. 차별화 포인트 (시연 시 강조)

미팅에서 "시중 AI로 다 할 수 있잖슴 → 차별점?" 질문 받았습니다. 답변할 차별화 포인트:

```
1. 정확도 다단계 검증
   수집 → 신뢰도 분류 → 재무 검증 → 사람 검토 플래그
   "API 한 번 호출해서 답 받는 시중 AI와 다릅니다"

2. 뉴스↔재무 연결 (다른 도구에 없음)
   "왜 이 액션을 했는지 숫자로 설명"
   삼성SDS 분기 매출, LG CNS AI 매출 비중 자동 추적

3. 선제 탐지 + 폐쇄망 대응
   외부 사이트 접속 어려운 환경에서
   이메일 한 통으로 핵심 정보 전달

4. SI 특화 도메인 지식
   삼성SDS 물류 제외, ITS만 분석 등
   섬세한 도메인 룰 반영
```
