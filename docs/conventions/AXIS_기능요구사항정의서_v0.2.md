| **예외 흐름** | ① 자격 증명 불일치 → "이메일 또는 비밀번호 오류"<br>② 5회 이상 실패 → 계정 임시 잠금 (10분)<br>③ 비활성 계정 → "이메일 인증 필요" 안내 |
| **사후 조건** | 세션 쿠키 발급, 마지막 로그인 시각 기록 |
| **관련 화면** | /login |
| **비고** | 모든 보호된 API에 Bearer 토큰 검증 미들웨어 적용 |

### FR-003 뉴스 크롤링

| 항목 | 내용 |
|---|---|
| **요구사항명** | 다중 소스 뉴스 자동 크롤링 |
| **업무 영역** | 에이전트 / 배치 |
| **관련 액터** | Collection Agent (자동), 관리자 (수동 트리거) |
| **기능 설명** | 네이버 뉴스 API, Google News RSS, IT 전문지 RSS에서 4개 Peer사(삼성SDS, LG CNS, 현대오토에버, 포스코DX) 관련 기사를 24/7 자동 수집한다. 키워드 전략 3레이어 적용. |
| **사전 조건** | API 키 발급 완료, RSS 소스 등록 완료 |
| **기본 흐름** | 1) 스케줄러가 주기 도달 시 트리거 (Layer1: 일간, Layer2: 매시간, Layer3: 5분)<br>2) 각 소스별 크롤러 비동기 실행<br>3) 응답 파싱 → 정규화<br>4) raw_articles 테이블 저장<br>5) 중복 URL 사전 필터링<br>6) DeduplicationAgent로 메시지 발행 |
| **예외 흐름** | ① 네이버 API 한도 초과 → 다음 주기까지 대기, 알림<br>② RSS 응답 실패 → 3회 재시도 후 로그 기록<br>③ 파싱 실패 → quarantine 테이블로 격리<br>④ Rate limit (429) → exponential backoff |
| **사후 조건** | raw_articles에 신규 레코드, 수집 통계 업데이트 |
| **관련 화면** | /admin/sources, /raw-articles |
| **비고** | SNS·블로그·카페 자료는 수집 대상에서 제외 (1차 미팅 §2.1) |

| **관련 액터** | Collection Agent (자동) |

| **사전 조건** | DART API 키 발급, 4사 corp_code 매핑 완료 |
| **기본 흐름** | 1) 매일 09:00 스케줄러 트리거<br>2) 4사 corp_code 순회<br>3) 신규 공시 목록 조회 (API)<br>4) 공시 메타데이터 저장 (peer_disclosures 테이블)<br>5) 첨부 PDF 다운로드 큐 등록<br>6) 본문 텍스트 파싱<br>7) 수주·재무 관련 항목은 peer_financials에 추출 |
| **예외 흐름** | ① API 응답 누락 → 재시도, 운영자 알림<br>② PDF 다운로드 실패 → 큐 보류, 다음 주기 재시도<br>③ 파싱 불가 PDF → quarantine, 수동 검토 큐 |
| **사후 조건** | peer_disclosures, peer_financials 갱신, evidence_chain에 출처 등록 |
| **관련 화면** | /admin/sources, /peers/{id} |
| **비고** | 분기 backfill 배치 별도 운용 (12개월치 일괄 수집) |
